# Bike_Sales_Analysis
This project focuses on analyzing customer bike purchasing behavior using Microsoft Excel.  
The goal of this project was to transform raw customer data into meaningful business insights through data cleaning, transformation, visualization, and dashboard creation.

## Tools & Features Used
- Microsoft Excel
- Data Cleaning
- Data Transformation
- Pivot Tables
- Pivot Charts
- Slicers & Filters
- Interactive Dashboard Design

## Analysis Performed
The dashboard analyzes customer purchasing patterns based on:
- Age Brackets
- Income
- Occupation
- Education
- Region
- Commute Distance

## Key Insights
- Customers with higher income showed higher bike purchase trends.
- Middle-aged customers were more likely to purchase bikes.
- Commute distance influenced purchasing behavior.
- Customer demographics helped identify buying patterns.
